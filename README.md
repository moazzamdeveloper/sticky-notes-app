# 📌 Sticky Notes App

A colorful **Sticky Notes** application with create, edit, delete, and localStorage support.

## Features
- Create new sticky notes
- Edit note content
- Delete notes
- Different random colors
- Data persists with `localStorage`
- Simple & clean UI

## How to Run
Open `index.html` in your browser.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
